   # Controller Tuner Platform

   A full-stack web application for tuning controllers on dynamic systems, built with FastAPI, React, and Docker.

   ## Tech Stack
   - **Backend:** FastAPI, Python, NumPy
   - **Frontend:** React, Tailwind CSS, Vite
   - **Deployment:** Docker Compose
